Cara Main

Kontrol Keyboard

↑ / W gas   ↓ / S rem dan mundur
← → / A D belok
Shift / Spasi lompat kecil dan drift
E / Ctrl pakai item   N / Q tahan untuk NOS
R kembalikan ke lintasan   Esc / P jeda   M suara

Layar sentuh: gas otomatis. Tekan panah kiri atau kanan untuk membelok (geser jari untuk berpindah), ikon tikungan (tahan) untuk lompat dan drift, botol untuk NOS, ikon item untuk jurus, dan cakram untuk rem. Gamepad juga didukung.

Power-Slide (Drift)

Sambil menikung, tekan Shift untuk melompat, lalu tahan untuk drift. Percikan berubah kuning, oranye, biru seiring lama drift. Lepas tombol untuk menembakkan turbo. Semakin lama, semakin kencang.

Start Turbo

Tekan gas tepat saat hitung mundur berganti ke GAS! untuk start roket.

Mangga 🥭

Setiap mangga memberi poin (makin banyak mangga, makin besar poinnya), mengisi NOS 10%, dan menambah kecepatan puncak. Tahan tombol NOS untuk menyemburkan nitro. Dengan 10 mangga, item menjadi versi tiga kali lipat. Terkena serangan membuatmu kehilangan 2 mangga.

Kotak Misteri

🌶️ Sambal: peluru pedas pencari sasaran
📌 Paku: ranjau di belakangmu
🛡️ Tameng: kebal dari serangan
⚡ Turbo: dorongan kecepatan
Pembalap di belakang mendapat item lebih bagus.

Papan Turbo & Lompatan

Panah biru-oranye di jalan memberi dorongan. Rampa kuning-hitam melontarkanmu ke udara.
